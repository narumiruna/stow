# ADR 0004: v0.1 Automated Test Scope

- Status: Accepted
- Date: 2026-08-02

## Decision

The repository's complete local automated UI run targets only:

1. the newest available iPhone simulator on the newest installed iOS runtime; and
2. the current macOS host.

Core/unit tests and unsigned iOS/macOS builds remain part of every CI quality gate. iPad and multi-version/device combinations are not part of the complete automated run. The local-only `Scripts/ui_tests.sh` runs macOS UI tests and selects the newest installed iPhone runtime dynamically for iOS UI tests. `Scripts/ci.sh` and CI workflows never invoke UI tests or `Scripts/ui_tests.sh`.

## Consequences

- Shared SwiftUI and core behavior still compile for iPadOS through the universal iOS target, but iPad-specific UI execution is not a v0.1 automated release gate.
- The broader matrix remains useful as diagnostic documentation, not a required routine run.
- Capability-dependent CloudKit and App Store signing checks remain separate external release gates; this decision does not make unsupported provisioning succeed.
