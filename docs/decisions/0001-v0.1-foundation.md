# ADR 0001: Stow v0.1 Foundation

- Status: Accepted
- Date: 2026-08-02

## Decisions

- Deploy to iOS/iPadOS 17.0+ and macOS 14.0+.
- Build with Xcode 26.6 and Swift 6.3 in Swift 6 language mode.
- Use the owned `narumi.dev` namespace: host bundle identifier `dev.narumi.stow` on iOS/iPadOS and macOS, with extensions `dev.narumi.stow.share.ios` and `dev.narumi.stow.share.macos`.
- Use App Group `group.dev.narumi.stow` and CloudKit container `iCloud.dev.narumi.stow`.
- The repository owner owns signing and CloudKit production deployment. Automatic signing selects a local Apple Development team; no team ID or signing credential is committed.
- Accept attachments up to 100 MB each. Extensions reject imports that cannot finish within their remaining execution time. Warn when Stow-owned local data exceeds 10 GB; do not silently evict source attachments.
- Keep product metrics on-device as aggregate counters, disabled by the user through Settings. Do not add a third-party analytics SDK or transmit captured content.
- Resolve concurrent metadata edits with CloudKit/SwiftData record-level last-writer-wins. Use stable UUIDs and idempotent capture IDs to prevent duplicate ingestion. Never merge binary payloads.
- Implement bundled, non-executing syntax presentation for user-selected languages. v0.1 highlights common comments, strings, numbers, and keywords without parsing or running code and has no external dependency.
- Target median local search below 50 ms and p95 below 150 ms for 10,000 mixed items on the reference Apple-silicon Mac; target a full index rebuild below 5 seconds.
- Target warm app launch below 1 second, capture commit below 1 second after provider loading, and retrieval-panel presentation below 250 ms on supported reference hardware.

## Consequences

SwiftData, SwiftUI, CloudKit private databases, and modern transfer APIs can be used without compatibility shims. Signing remains environment-local, while simulator and unsigned macOS builds remain reproducible in CI. Centralized product analytics are intentionally unavailable in v0.1 to preserve the privacy promise.
