# Stow v0.1 Accessibility and Presentation Audit

- Date: 2026-08-03
- Scope: newest available iPhone simulator and current macOS host (ADR 0004)
- Result: Pass in the owner-approved automated scope

## iPhone

`StowUITests` runs XCTest accessibility audits for the standard interface and dark mode with Reduce Motion enabled. A separate accessibility-XXXL test verifies that the primary empty-state action remains reachable by scrolling. The audit drove fixes for hit target size, text clipping, Dynamic Type layout, and empty-state contrast.

## macOS

`StowMacUITests` queries all navigation destinations and quick-panel/quick-add controls through the accessibility hierarchy. Global shortcut registration has a visible, non-sensitive status, and conflict errors provide alternate shortcut choices in Settings.

## Privacy and sensitive previews

All root content is marked privacy-sensitive. When the iOS scene is inactive, Stow overlays saved content with an opaque material and a generic “Stow is private” message. Stow does not schedule notifications containing saved content.

## Localization readiness

All user-facing static SwiftUI literals use localized string-key initializers. `xcodebuild -exportLocalizations -exportLanguage en` successfully produced an English localization catalog. Dynamic item titles, content, filenames, dates, and source-app names intentionally remain user/system data rather than localization keys.
