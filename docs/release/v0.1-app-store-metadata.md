## Description

Stow is a private, local-first content inbox for Apple devices.

Capture a link, a thought, a code snippet, an image, or a file in one explicit save. Process it later from Inbox, pin what matters, archive what is finished, and find anything quickly with private on-device search.

On Mac, newly copied text, links, images, and files can be saved automatically while Stow is running; clipboard monitoring can be disabled in Settings. Use Option-Shift-S to capture without breaking focus and Command-Shift-V to retrieve recent items from a keyboard-first panel. Your library remains usable offline and is designed to synchronize through your private iCloud database when iCloud is available.

Stow contains no ads, social features, AI analysis, or third-party analytics. Captured content is not sent to an external Stow service.

## Review notes

- The app stores user-selected content locally and in the user's private iCloud database.
- No login is required beyond the system iCloud account.
- Share extensions require one explicit Save tap and stage captures atomically for host ingestion.
- macOS default shortcuts are Option-Shift-S for capture and Command-Shift-V for retrieval; alternatives are in Settings if registration conflicts.
- Photo Library access is requested only when the user chooses Save Image.

## Privacy questionnaire draft

- Tracking: No.
- Third-party advertising: No.
- Data linked to the user by the developer: None transmitted to the developer.
- User Content: stored on device and, when enabled, in the user's private CloudKit database; not accessible to the developer through a Stow service.
- Diagnostics/analytics: aggregate product counters remain on device and can be disabled.
- Required-reason APIs: UserDefaults (`CA92.1`) and app-container file timestamps (`C617.1`), declared in `Configuration/PrivacyInfo.xcprivacy`.
