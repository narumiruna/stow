## Provisioning evidence

The prior signed iOS device build created development profiles but failed because the profiles did not include `com.apple.security.application-groups` or `com.apple.developer.icloud-container-identifiers`. A signed macOS archive failed because the team could not create suitable Mac development profiles. Unsigned builds intentionally omit runtime CloudKit and fall back to the same local App Group store for development.
