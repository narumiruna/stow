# Stow v0.1 Scope Audit

- Date: 2026-08-02
- Result: Pass

The generated project contains only iOS/iPadOS and macOS apps, their share extensions, and test bundles. `StowCore` depends only on Apple system libraries (`Foundation`, `SwiftData`, `SQLite3`, `ImageIO` where platform UI requires it). The macOS app includes an on-device clipboard monitor that can be disabled in Settings; it saves supported clipboard changes directly to the user's Inbox. There are no Web, Android, Windows, collaboration, account server, browser extension, OCR, AI/model inference, recommendation, or code-execution targets or dependencies.

Code presentation is a bundled regular-expression colorizer. It does not classify, parse, compile, transmit, or execute captured code. Link enrichment stores ordinary metadata and does not create full webpage snapshots. Unsupported files retain their original bytes and use a generic file presentation rather than promising an inline preview.
